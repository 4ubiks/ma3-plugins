# MAPRACTICE
This is a tool that you can run that will generate a 'random' collection of an MA3 command 'DO -> THIS -> HERE'

I use it to practice keystrokes and memorizing what buttons are where. 

Copy this folder only into a directory, run 'make', and then press enter to generate a new command. Type it as fast as you can!

To exit, press any key followed by enter. For example, 'f' + 'Enter'. 

You'll then see the number of commands you've practiced with.
